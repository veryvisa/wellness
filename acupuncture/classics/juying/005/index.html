Chapter 5十二原穴歌

Original · plain Chinese · English · notes原文 · 白话 · 英文 · 学习要点

Classical texts医书对照 › Zhenjiu Juying (Gatherings from Eminent Acupuncturists)针灸聚英 › Chapter 5十二原穴歌

甲出丘墟乙太冲。

天干属甲的胆经，其原穴出于丘墟；属乙的肝经，其原穴是太冲。

For the stem Jia (Gallbladder channel), the source point emerges at Qiuxu; for the stem Yi (Liver channel), the source point is Taichong.

💡 【术语】原穴：脏腑原气经过、留止的穴位，是反映和调治本脏腑的要穴。十二经各有一个原穴。甲乙属木，甲为阳木配胆，乙为阴木配肝，这是天干配脏腑的规律，也是脏腑表里配对的规律。【穴位】丘墟 GB40，在足外踝前下方，趾长伸肌腱外侧凹陷中；太冲 LR3，在足背第1、2跖骨结合部前方凹陷中。【临床】GB40 常用于胁肋痛、踝关节扭伤、足下垂；LR3 用于头痛眩晕、情志不舒、月经不调。二穴同属肝胆表里，常配合使用。【今天是否适用】天干配脏腑是古代五行配属的记忆法，今天主要当作记忆口诀。原穴本身的定位与主治仍是考试和临床的核心内容。现代研究多从神经、血管、内分泌等角度解释穴位效应，对「原气」本身没有一一对应的解剖结构，只能当作传统理论来理解。

丙歸腕骨是原中。

天干属丙的小肠经，其原穴归于腕骨，腕骨就是原穴所在。

For the stem Bing (Small Intestine channel), the source point belongs at Wangu; Wangu is the source point.

💡 【术语】丙属阳火，配小肠。【穴位】腕骨 SI4，在手掌尺侧，第5掌骨基底与三角骨之间的赤白肉际凹陷中。【临床】主治头项强痛、耳鸣、黄疸、手腕痛、消渴。【注意】阳经在井荥输经合之外另有原穴，排在输穴之后、经穴之前。小肠经依次是少泽、前谷、后溪、腕骨、阳谷、小海，腕骨 SI4 是原穴，与输穴后溪 SI3 不是同一个穴。《难经·六十二难》解释说三焦行于诸阳，所以阳经多置一个原穴。【今天是否适用】取穴定位完全沿用，天干配属只作记忆用。

丁出神門原內過。

天干属丁的心经，其原穴出于神门；原气经过这里，属于阴经原穴与输穴同为一穴的情况。

For the stem Ding (Heart channel), the source point emerges at Shenmen; the source qi passes through here, and as on every yin channel the source point coincides with the stream point.

💡 【术语】丁属阴火，配心。【穴位】神门 HT7，在腕前区，腕掌侧横纹尺侧端，尺侧腕屈肌腱的桡侧缘。【医理】《难经·六十六难》提出「五脏俞者，三焦之所行，气之所留止也」，阴经以输穴代原，所以神门既是输穴也是原穴。《灵枢·九针十二原》原本只列五脏各左右二原，心的原是大陵（心包），神门代心的说法是《难经》以后才定下来的。【临床】HT7 是安神定志的要穴，用于失眠、心悸、健忘、癫狂。考试常考「心经原穴是神门」。【今天是否适用】神门治失眠、心悸，在临床上很常用，有研究观察其对睡眠和自主神经功能的影响。「心不受邪，由心包代受」是古代理论，今天不按字面理解。

戊胃冲陽氣可通。

天干属戊的胃经，其原穴是冲阳，经气由此可以相通。

For the stem Wu (Stomach channel), the source point is Chongyang, through which the qi can flow freely.

💡 【术语】戊属阳土，配胃。【穴位】冲阳 ST42，在足背，第2跖骨基底部与中间楔状骨关节处，足背动脉搏动处。【临床】主治胃痛、腹胀、面肿、口眼歪斜、足痿无力。【特点】冲阳处的动脉就是张仲景诊察的趺阳脉，用来判断胃气的有无。足背动脉搏动处，今天仍可用于检查下肢血供，如糖尿病足的评估。【今天是否适用】取穴、诊脉意义可用，要注意足背动脉处针刺时避开血管。

己出太白庚合谷。

天干属己的脾经，其原穴出于太白；天干属庚的大肠经，其原穴是合谷。

For the stem Ji (Spleen channel), the source point emerges at Taibai; for the stem Geng (Large Intestine channel), the source point is Hegu.

💡 【术语】己属阴土，配脾；庚属阳金，配大肠。【穴位】太白 SP3，在足内侧，第1跖趾关节近端赤白肉际凹陷中；合谷 LI4，在手背，第2掌骨桡侧的中点处。【医理】SP3 是脾经输穴兼原穴，属土，符合「阴经以输代原」。LI4 是大肠经的原穴，大肠经五输依次是商阳、二间、三间、（原）合谷、阳溪、曲池，合谷排在输穴三间之后。【临床】SP3 用于脾虚、腹胀、泄泻、痰湿；LI4 用于头面五官疾病、外感发热、止痛，并有「面口合谷收」的四总穴说法。LI4 与 LR3 合称「四关」，用于镇静止痛。【今天是否适用】LI4 常用于止痛，是针刺镇痛研究用得较多的穴。合谷在孕期列为禁用或慎用，是教材要点。

辛緣本出太淵同。

天干属辛的肺经，其原穴同样出于它本经的太渊，原穴与输穴也是同一个穴。

For the stem Xin (Lung channel), the source point likewise comes from its own channel at Taiyuan, where the source and the stream point are one and the same.

💡 【术语】辛属阴金，配肺。「本出」指原穴出自本经；「同」指与前面阴经一样，以输穴为原。【穴位】太渊 LU9，在腕前区，桡骨茎突与舟状骨之间，拇长展肌腱尺侧凹陷中，桡动脉搏动处。【医理】LU9 又是八会穴之一的「脉会」，肺朝百脉，所以太渊可诊脉、调脉。【临床】主治咳嗽、气喘、咯血、无脉症、胸痛。【今天是否适用】取穴与主治沿用。桡动脉处针刺要避开血管，轻刺不宜过深；肺朝百脉与寸口诊脉的关系是传统理论，今天用于解释中医的脉诊原理。

壬歸京骨期中過。

天干属壬的膀胱经，其原穴归于京骨，是在这里原气经过。

For the stem Ren (Bladder channel), the source point belongs at Jinggu, where the source qi is said to pass.

💡 【术语】壬属阳水，配膀胱。「期中过」说的是原气经过此穴。【穴位】京骨 BL64，在足外侧，第5跖骨粗隆前下方，赤白肉际处。【临床】主治头痛项强、腰腿痛、癫痫、目翳。【特点】膀胱经穴位最多，共67穴；京骨排在输穴束骨 BL65 之后、经穴昆仑 BL60 之前。【今天是否适用】可用于头项与腰腿痛的远端配穴。天干配属仅作记忆口诀。

癸出太谿原穴逢。

天干属癸的肾经，其原穴出于太溪，在这里可以遇到原穴。

For the stem Gui (Kidney channel), the source point emerges at Taixi, where one meets the source point.

💡 【术语】癸属阴水，配肾。【穴位】太溪 KI3，在踝区，内踝尖与跟腱之间的凹陷中。【医理】肾为先天之本，藏精；原气源于肾间动气，所以肾经原穴太溪特别重要，是滋肾阴的代表穴。【临床】主治月经不调、遗精阳痿、耳鸣耳聋、咽喉肿痛、腰痛、失眠、消渴。该处有胫后动脉搏动，古称「太溪脉」，可诊肾气。【今天是否适用】太溪在临床上常用，可用于肾虚证、内踝周围疼痛。肾间动气是古代理论概念，没有对应的解剖结构；中医的「肾」也不等于解剖学的肾脏。

三焦壬是陽池穴。

三焦经的原穴是阳池，它与天干壬相配。

For the Sanjiao (Triple Energizer) channel, the source point is Yangchi, which is matched with the stem Ren.

💡 【术语】三焦：古代六腑之一，主通行元气、水谷与水液，有「有名无形」的争议。三焦经又称手少阳经，在天干中与壬相附，因为壬为阳水，三焦主水道。这是子午流注一派的配法，膀胱经同样配壬，所以说三焦「附壬」。【穴位】阳池 TE4（也写作 SJ4），在腕后区，腕背侧远端横纹上，指伸肌腱的尺侧缘凹陷中。【临床】主治腕痛、耳聋、消渴、疟疾、咽喉肿痛。【今天是否适用】三焦的实质，现代没有对应的单一器官，多被理解为一种功能系统。阳池定位清晰，用于腕关节病变，如腕背痛、腱鞘炎。考试要记住三焦原穴是阳池，不是阳溪（LI5）。

包絡大陵癸又重。

心包络经的原穴是大陵，它也与天干癸相配，所以癸又重复出现。

For the Pericardium channel, the source point is Daling, which is also matched with the stem Gui, so Gui appears a second time.

💡 【术语】包络：心包络，是心的外围，代心受邪。心包经又称手厥阴经，与三焦互为表里，与肾同配癸，所以说「又重」。这种附配是为了凑足十二经配十干，因为十天干只有十位，十二经需要两经共用，所以三焦附壬、心包附癸。【穴位】大陵 PC7，在腕前区，腕掌侧远端横纹中，掌长肌腱与桡侧腕屈肌腱之间。【临床】主治心痛、心悸、胃痛、呕吐、失眠、癫狂、腕管综合征相关症状。【今天是否适用】大陵常用于腕管综合征周围症状，以及心神不宁、失眠。天干配属是古代配数的需要，今天只当作理解十二原穴与口诀的辅助。最后总结十二原穴（WHO 代码）：GB40、LR3、SI4、HT7、ST42、SP3、LI4、LU9、BL64、KI3、TE4、PC7。
